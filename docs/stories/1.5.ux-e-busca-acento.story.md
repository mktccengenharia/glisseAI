## Contexto

Feedback direto do usuário sobre o app em uso: travessões longos ainda visíveis na UI (fora do texto gerado pela LLM, que já tinha sido tratado na Story 1.1), busca não tolera falta de acentuação, seletor de versão ultrapassa a tela sem opção de rolar, e falta um botão para voltar/sair da conversa.

## Acceptance Criteria

1. **AC1:** `ProcedureCard` não deve exibir o caractere `—` (travessão longo) em nenhum lugar — nem como placeholder de campo vazio, nem como separador de texto.
2. **AC2:** Mensagem de "nenhum resultado encontrado" não deve usar `—`.
3. **AC3:** Buscar um termo sem acentuação (ex: "dissecçao") deve encontrar procedimentos com acentuação (ex: "Dissecção"), sem exigir que o usuário digite acentos.
4. **AC4:** O dropdown do seletor de versão deve ter altura máxima com rolagem interna, nunca ultrapassando a tela sem meio de acessar os itens cortados.
5. **AC5:** Deve existir um botão no cabeçalho do chat para voltar à tela inicial (encerrando a conversa atual).
6. **AC6:** `npm run lint`, `npm test`, `npm run build` continuam passando.
