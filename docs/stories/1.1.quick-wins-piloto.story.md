## Acceptance Criteria

1. **AC1 — Sem travessão longo na resposta da LLM:** o `systemPrompt` em `src/app/api/chat/route.js` deve instruir explicitamente o modelo a nunca usar o caractere `—` (travessão), preferindo vírgula, ponto ou frases curtas.
2. **AC2 — Resposta estruturada:** o `systemPrompt` deve instruir o modelo a organizar respostas com mais de um procedimento em formato claramente segmentado (ex: listas/parágrafos curtos por item), em vez de texto corrido.
3. **AC3 — Copiar código isoladamente:** o `ProcedureCard` (`src/app/page.jsx`) deve ter um botão que copia apenas o código do procedimento para a área de transferência.
4. **AC4 — Copiar nome isoladamente:** o `ProcedureCard` deve ter um botão que copia apenas o nome/descrição do procedimento para a área de transferência.
5. **AC5 — Botão "copiar tudo" preservado:** o comportamento atual do botão "Copiar" (código + procedimento + porte) deve continuar funcionando sem regressão.
6. **AC6 — Sem regressão de lint/build:** `npm run lint` e `npm run build` devem passar sem novos erros.
